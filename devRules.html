Правила использования ABartaj для dev привелегий

Правила ABartaj обязательны для всех разработчиков, публикующих приложения на платформе.

1. Общие положения

Настоящие правила регулируют отношения между платформой ABartaj и разработчиками приложений. Все разработчики обязаны:

  • Предоставлять корректную информацию о приложении.
  • Обеспечивать соответствие приложения законодательству страны публикации.
  • Не использовать платформу для распространения запрещенного или вредоносного контента.

2. Требования к контенту

Разработчик несет ответственность за контент своего приложения. Контент должен:

  • Быть безопасным для пользователей всех возрастов.
  • Не нарушать авторские права и права третьих лиц.
  • Не содержать насилия, дискриминации или непристойных материалов.
  • Принимать во внимание локальные законодательные нормы.

3. Работа с персональными данными

Приложения, которые собирают или обрабатывают персональные данные пользователей, обязаны:

  • Иметь политику конфиденциальности, доступную для пользователей.
  • Собирать только необходимые данные для функционирования приложения.
  • Обеспечивать защиту данных от утечки и несанкционированного доступа.

4. Монетизация

  • Все способы монетизации должны быть прозрачными для пользователей.
  • Реклама и встроенные покупки не должны нарушать пользовательский опыт.
  • Разработчик обязан предоставить точную информацию о стоимости и условиях оплаты.

5. Обновления и поддержка

  • Разработчик обязан своевременно выпускать обновления для устранения ошибок и уязвимостей.
  • Обновления не должны ухудшать функциональность приложения без уведомления пользователей.
  • Разработчик должен обеспечивать доступную поддержку для пользователей.

6. Нарушения правил

  • В случае нарушений приложение может быть временно или полностью удалено с платформы.
  • Систематические нарушения ведут к блокировке аккаунта разработчика.
  • Все спорные вопросы решаются администрацией ABartaj на свое усмотрение.

7. Ответственность

Разработчик несет полную ответственность за функциональность и содержание приложения, а также за последствия его использования пользователями.

8. Заключительные положения

  • Правила действуют с момента публикации приложения на платформе.
  • Администрация ABartaj оставляет за собой право изменять правила без предварительного уведомления.
  • Продолжение использования платформы после изменений означает согласие с новыми правилами.

Рекомендуется регулярно проверять актуальную версию правил.
